# Jabberwocky Translation

Translate text between plain English and the Jabberwocky dialect using the
vocabulary below. Jabberwocky keeps English grammar and sentence structure
but swaps key words for nonsense equivalents.

## Vocabulary

| English             | Jabberwocky      |
|---------------------|------------------|
| afternoon/evening   | brillig          |
| active/excited      | slithy           |
| walk/wander         | gyre             |
| spin/dance          | gimble           |
| meadow/field        | wabe             |
| fragile/delicate    | mimsy            |
| birds               | borogoves        |
| lost/wandering      | mome             |
| pigs/creatures      | raths            |
| angry/upset         | outgrabe         |
| beware              | beware (same)    |
| monster/beast       | Jabberwock       |
| jaws/mouth          | jaws (same)      |
| claws               | claws (same)     |
| bird (dangerous)    | Jubjub bird      |
| beast (wild)        | Bandersnatch     |
| sword               | vorpal sword     |
| enemy/foe           | manxome foe      |
| tree                | Tumtum tree      |
| think/ponder        | uffish           |
| stomped/charged     | whiffling        |
| crashing through    | burbling         |
| fast/swift          | galumphing       |
| killed/defeated     | snicker-snack    |
| head/trophy         | head (same)      |
| celebrate/rejoice   | frabjous         |
| hooray/wonderful    | callooh callay   |
| chuckled/laughed    | chortled         |

## Rules

1. **Keep English grammar intact.** Only swap vocabulary words, don't
   rearrange sentences.
2. **Words not in the table stay as-is.** Jabberwocky only replaces
   specific words — articles, prepositions, names, and unmapped words
   pass through unchanged.
3. **Going English → Jabberwocky:** replace English words with their
   Jabberwocky equivalents wherever they appear.
4. **Going Jabberwocky → English:** replace Jabberwocky words with their
   English equivalents.
5. **Be creative with near-matches.** If the user says "happy" and the
   closest match is "celebrate/rejoice → frabjous," use it. Note the
   creative liberty.
6. **Show your work.** After the translation, list which words were
   swapped so the user can learn the vocabulary.
